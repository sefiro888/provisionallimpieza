# Sitio de limpieza profesional en Madrid

Web estática multipágina preparada para presentar servicios de limpieza de sofás, colchones, alfombras, vehículos y otras tapicerías a domicilio.

## Vista local

Con Python instalado:

```powershell
python -m http.server 4173
```

Después abre `http://127.0.0.1:4173/`.

La identidad visual, el logotipo y el dominio definitivo se incorporarán cuando estén confirmados.
